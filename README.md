# ContentFarm Professional

ContentFarm adalah aplikasi desktop untuk mengelola upload video ke berbagai platform media sosial secara terjadwal.

## Status

🚧 Development (v0.1.0)

## Platform

- YouTube Shorts
- TikTok
- Instagram Reels

## Tech Stack

- Python
- NiceGUI
- SQLite
- SQLAlchemy
- APScheduler
- Watchdog
